    LINK SAFETY

    Inspect a URL's structure for common warning signs. This tool does not visit the link or confirm whether a site is malicious.

    Never open a suspicious link just to test it. URL checks are heuristic and may miss malicious sites or flag legitimate ones.

    Current prototype limitations

    This version uses transparent rule-based text analysis and local URL heuristics. Screenshot OCR extracts text but can make mistakes. No real AI model is connected yet, and the tool does not verify sender identities, visit links or guarantee scam detection.
